2Try the Action Trigger path

These messages match an entry in the ActionMappings SQL table. The intent router sends them down the action lane → Service Bus action-queue → ActionWorker → SignalR back to the SDK. Watch for the toast notification.

3Try the LLM Generation path

These don't match an action. They go to RAG: KB retrieval (tenant config) → LLM. The first call is a cache MISS and writes to the semantic cache; the second identical call is a cache HIT.

4Try the circle gesture

Hold Alt and drag your mouse to circle any region of this page. The SDK extracts the DOM text inside the region and sends it as capturedText alongside the question "Tell me about this circled content".

5Trigger a proactive recommendation

The Activity Mining Worker reads activity events. After about 5 events in 30 seconds it asks the LLM to draft a nudge and pushes it via SignalR. Click the button below to fire 6 quick events.

6Inspect the data layer

Conversation history and activity events are stored in blob storage as JSONL (Append Blobs in Azure, JSONL files locally for the demo). Cache, audit, profile, and action mappings stay in SQL. Click to refresh.
